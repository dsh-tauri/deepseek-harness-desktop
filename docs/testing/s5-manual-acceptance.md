# S5 桌面壳集成 — GUI 手动验收清单（无头环境无法目视的走查项）

S5 验收中「数据面全旅程」「壳层命令/单测/lint」「capability」「旧概念残留」
已自动化并留证（见 `s5-ssh-e2e-evidence.md` 与下方对应节）。以下条目需要
真人目视 `pnpm tauri dev` GUI（无头环境**未验证**），逐项勾选：

## 准备

- [ ] 分支 `feat/ssh-remote-machines-v14`（origin/main v0.14.1 适配）上
      `pnpm install && pnpm build:plugins`，`pnpm tauri dev`
      （debug 端口 3081 / DSH_HOME `~/.dsh.dev`；注意 1420 端口空闲）。
- [ ] dev 机器可在 web 设置页添加（host=dev 别名即被 ~/.ssh/config 发现）；
      如远端 home 层 pin 了 webserver 端口，机器配置里填自定义启动命令
      （证据文档「dev 机器环境注记」有可抄的一条）。

## A 切换器（navbar）

- [ ] 就绪态 navbar 出现地球图标切换器；安装/错误/预装引导阶段不出现。
- [ ] 下拉含「本地」项 + 机器项（手动机器与 ~/.ssh/config 别名机器都在）。
- [ ] 色点语义：设了标识色的机器任何状态都显示机器色；无色机器
      已连接=绿 / 连接中·测试中·重连中=琥珀 / 已放弃=红 / 其余=灰；
      未连接行整体 60% 透明度。
- [ ] 状态文案随轮询刷新（连接中→已连接；重连中（含下次重试）/已放弃）。
- [ ] 已放弃机器行悬停可见 lastError 原因（title 提示）。
- [ ] 点击已连接机器：内容区立即切到该机器（触发按钮显示机器名+色点）。
- [ ] 点击未连接机器：发起连接，就绪后自动切换（不闪空端口页）。
- [ ] 点击「本地」：回本地实例（远端连接保持）。
- [ ] 空态（无机器）：菜单出现引导文案；「管理机器」点击弹 toast 指路
      web 设置页 SSH 面板。

## B 内容区与着色

- [ ] 连接勾选了 tintBorder+标识色的机器：内容区四周出现 2px inset ring
      （机器色），切换回本地后消失。
- [ ] 未勾 tintBorder 或无标识色：不描边。
- [ ] 远端模式下 iframe 内 web 界面可正常交互（含其设置页 SSH 面板）。

## C 弹窗桥命令（web 设置页 SSH 面板内）

- [ ] 桌面 iframe 内打开 web 设置页 SSH 面板：机器卡片出现「新窗口打开」
      按钮（remote_bridge_ping 探测成功）。
- [ ] 点击后打开独立窗口（标题 `DSH Remote · <machineId>`，1280×840），
      加载隧道 URL 的远端 web 界面；再次点击聚焦已有窗口（不重复开窗）。
- [ ] 同一面板在纯浏览器打开（直接访问服务 URL）：按钮隐藏（探测超时）。

## D 降级与恢复（验收标准 3）

- [ ] 停掉本地实例（设置里 Stop 服务或杀进程）：切换器下拉出现
      「本地实例不可达」提示，机器项禁用（半透明、不可点），不弹错误弹窗。
- [ ] 重启实例并聚焦窗口：提示消失、机器项恢复可点。
- [ ] 降级期间既有机器列表不清空。

## E 断线自动恢复（S3 联动，GUI 观察）

- [ ] 活动机器被服务端掐线（远端重启 sshd / 断网）：切换器显示「重连中」
      并附下次重试倒计时（如「（42s 后重试）」），内容区保持指向该机器
      （隧道 URL 粘性，不出空端口）。
- [ ] 恢复后自动回到「已连接」，界面随之可用（无需手动刷新）。
- [ ] 切换器底部「断开当前远端连接」（仅远端活动时出现）：点击后视图
      立即回本地、机器状态点变灰。
- [ ] 已连接/曾连接机器的状态文案后缀凭据类型（agent/密钥/密码）。
- [ ] 点击未连接机器后、首轮轮询回报前：该项立即显示「连接中」且全部
      远端项禁用（pending 反馈），就绪后自动切换。

## F 设置页交互（web 设置页 SSH 面板，已重做）

- [ ] 面板为显示优先：每台机器一行（色点/名称/主机/状态/动作），
      点「编辑」才展开内联表单；保存按行立即生效并收起（无全局保存按钮）。
- [ ] 「添加机器」打开弹窗表单：填主机后 ID 自动派生（如 `ops@10.1.1.1`
      → `10-1-1-1`），撞名自动 -2 避让；手改 ID 后不再自动派生；
      主机空/ID 非法/ID 占用时内联报错且提交禁用。
- [ ] 删除：确认弹窗后立即生效（行消失）。
- [ ] 勾选边框着色+标识色：行左侧出现 2px 标识色条（保存并刷新后呈现）。
- [ ] 连接/安装进行中：行状态旁出现步骤条（握手/安装/启动/探测，
      只显示真实走过的阶段，当前阶段高亮）；落定后步骤条收起。
- [ ] 探测（测试）已连接机器：状态保持「已连接」不闪回「未连接」；
      探测失败只在状态里追加原因。
- [ ] 已连接机器点「新窗口打开」：按钮在飞期间显示「正在打开…」并禁用，
      落定复原；失败时行内联报错。
- [ ] 桌面桥探测期间：「新窗口打开」先以禁用占位出现，探测落定后原位
      点亮（桌面端）或移除（纯浏览器），无布局跳动。

## F2 壳层原生管理面板与连接弹窗（切换器直达，本轮新增）

- [ ] 切换器底部「管理机器…」打开壳层面板（不再是 toast 指路）：
      列表含 user@host:port 副标题与状态；行内动作连接/断开/新窗口/编辑/
      删除齐备。
- [ ] 面板内「添加机器」：内联表单，主机派生 ID（撞名 -2 避让）、
      主机空/ID 非法/占用内联报错且保存禁用；保存即落盘并刷新列表。
- [ ] 编辑回填已存字段；密码/密钥口令 placeholder 提示「留空 = 保留已存」，
      留空保存不清除已存凭据。
- [ ] 删除经危险确认弹窗，确认后立即 remove 且行消失。
- [ ] 点击未连接机器（切换器或面板）：弹出连接进度弹窗——阶段步骤条 +
      实时日志尾滚动；可关闭（后台继续）；成功自动关闭并完成切换。
- [ ] 连接失败：弹窗定格直接原因 + 已走阶段 + 日志，「重试」重新发起；
      进行中手动关过弹窗的，失败时也会重新弹出。
- [ ] 已连接机器行尾「新窗口」图标：点击打开独立窗口且不触发当前窗口
      切换（行本体点击才是切换）。
- [ ] 本窗口切远端：iframe 直接显示远端界面，不再出现 "dsh web authentication required"（隧道自注 Cookie；会话 cookie SameSite=Strict 在 iframe 第三方上下文失效，?token= 只对顶层导航有效）
- [ ] 行尾新窗口（所有机器行常驻，未连接也可开）：弹出窗口与主窗口同一顶栏/窗口 chrome（macOS Overlay 标题栏+交通灯），启动即在该机器（未连接则窗内走连接流程）；两台机器可同时各开一窗，本窗口不被抢；远端界面与本体的 UI 一致（同一 dsh 版本）
- [ ] 远端界面带桌面插件面（侧边栏设置/会话等 dsh-tauri-* 面板与本地一致）；首连或插件更新后连接日志出现「同步桌面捆绑插件到远端」，二次连接无该日志（marker 命中跳过）
- [ ] 切换远端/远端首载：有「正在加载远端界面…」进度覆盖层，不空屏
- [ ] 连接进行中弹窗「取消连接」：引擎侧尝试真正中止（不等到 7 次重试
      耗尽），弹窗关闭且无失败定格；「关闭」则后台继续。
- [ ] ssh config 里带 `ProxyJump` 的主机（如 ops 经 dev）：连接经跳板
      建立，不再报 "Connection lost before handshake" 盲重试。
- [ ] 合并 v0.14.3 后回归：远端窗口交通灯与新 52px 导航栏对齐（y=28，
      非旧 24）；主/远端窗口均出现「文件/帮助」菜单；远端窗口内插件
      boot 正常（建窗走共享 `build_shell_window`，桥脚本按窗口注入）。
- [ ] 合并准备四项（09-20）：① 机器「远端档案」字段（默认 remote，含
      startCommand 覆盖时置灰）——连接日志远端按 `dsh --profile <name>`
      拉起，远端 ~/.dsh/profiles/<name> 含核心模板 + 桌面插件；② 远端实例
      的设置「SSH 远程机器」分区显示「目前正在 SSH 中（来自 <机器名>）」
      横幅且无管理入口（隧道内 POST session.role 应答 remote:true）；
      ③ 切换器「管理」直达 iframe 设置 SSH 分区（壳层不再有管理弹窗）；
      ④ dsh 主侧边栏出现「同步到远端」面板（插件/Skill 多选 + 逐项结果），
      设置页机器列表尾部不再有内嵌同步块。
- [ ] 插件退役回归（dsh-tauri-panel 并入 core 后）：连接日志出现
      「同步桌面捆绑插件（11 个）」且远端实例按新 profile 正常重启
      （不出现 cannot resolve profile bundle / EADDRINUSE 崩溃）；
      远端 profile 无退役包残留（wire 清理悬空托管链接）。
