# Codex 图集布局（仅用户明确要求时）

Pets 视频包不使用此布局，也不因旧宿主不支持视频就改用此分支。

dsh-tauri-pet 的 Codex 图集是固定网格：**8 列 × 11 行**，每格 192×208，整图 **1536×2288**，`spriteVersionNumber: 2`。

宿主只按「宽能被 8 整除、高能被 9 或 11 整除」切格，然后按下表取每行的帧。行的语义是固定的，不能重排。

上游素材（10 秒绿幕视频 → 透明动画）怎么映射到这张表、取帧与拼图的具体命令，见 `atlas-compose.md`；上游生成流程本身见 `dsh-pet-video-flow.md`。

| --- | --- | --- | --- | --- |
| 0 | 待机 idle | 6 | 280 / 110 / 110 / 140 / 140 / 320 | 是 |
| 1 | 向右移动 | 8 | 120（末帧 220） | 是 |
| 2 | 向左移动 | 8 | 120（末帧 220） | 是 |

## 行 0~8

这些是动作行，只使用本行的左侧若干格（帧数见上表），**末帧之后的格子必须完全透明**。留下旧像素的典型症状是动作播完后闪出残帧。

每行的帧数必须与上表**严格一致**：逐帧时长由渲染组件写死，多给一张就会被当成动作的一部分播出来，少给一张则该行后半段是空白。

## 行 9~10

这两行按角度采样朝向，共 16 个方向，平均分给两行：

- 行 9：000°、022.5°、045°、067.5°、090°、112.5°、135°、157.5°
- 行 10：180°、202.5°、225°、247.5°、270°、292.5°、315°、337.5°

`000°` 是画面向上（12 点方向）。正对镜头的中性朝向是死区，不占用 look 格，由第 0 行兜底。look 行必须 8 格填满。

## 会话活动 → 动作

桌宠的档位由 npm 包 `dsh-pet-component` 决定，图集只需要把行动作画对：

- 待机、思考、工作、结果、等待、运行、复查、成功、失败各自对应上表的一行。
- 拖动窗口时用第 1 行，不单独占一行。
- 会话里没有明确档位时回落到第 0 行。

## 自检

出一版图集后先跑 `validate-pet.mjs`，再在设置页里选中它，观察待机与一次完整对话是否走对行。逐帧时长写死在组件里，改图集不会改节奏。
